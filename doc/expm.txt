EXPM - Extended Presentation Manager library
============================================

EXPM is a LGPLv3 GUI extension library for Presentation Manager
(OS/2, ArcaOS / Warp 4.52).  It extends PM GUI elements with helper
routines whose names follow the natural style of Presentation Manager:
Win* for window-manager helpers, Gpi* for graphics, Dos* for kernel,
with the standard PM types (HWND, HAB, ULONG, BOOL, ...) and the
MPFROMMP/PFROMMP macros.  See also:

    https://www.edm2.com/index.php/Presentation_Manager_Functions

Directory layout
----------------

    Makefile.wat        Open Watcom 2.0 build file (run from project root)
    compile_wat.cmd     Command line script using wmake; generates compile.log
    README.md           Project readme
    dll\                Rebuilt library DLL (EXPM.DLL)
    lib\                Import library file (EXPM.LIB)
    h\                  Public headers (expm.h)
    src\                Source code of the library (one subdir per module)
    sample\             Application samples for using the library
    doc\                Documentation and information about the library


Module: ComboSup (combo box support)
------------------------------------

Merged from LIB-PM-ComboBoxSupport 1.1 (public domain, Dave Briccetti,
1990).  Provides two helpers to initialize a PM combo box: populate the
list and select an initial item.

Name mapping (original 16-bit -> EXPM):

    InitComboBox             -> WinInitComboBox
    InitComboBoxFromRcStrings -> WinInitComboBoxFromRes
    ICB_NOSELECTION (-1)     -> LIT_NONE  (defined in pmwin.h)

API reference
-------------

    USHORT EXPENTRY WinInitComboBox( HWND hwndOwner,
                                     ULONG idCombo,
                                     PCSZ *apszInit,
                                     LONG iInitialSelection );

        Populates the combo box identified by idCombo in the dialog or
        client window hwndOwner with the NULL-terminated array of
        strings apszInit, then preselects apszInit[iInitialSelection].
        Pass LIT_NONE as iInitialSelection to leave the combo with no
        initial selection.  Returns 0 on success.

    USHORT EXPENTRY WinInitComboBoxFromRes( HAB hab,
                                            HMODULE hmodRes,
                                            HWND hwndOwner,
                                            ULONG idCombo,
                                            PLONG alId,
                                            LONG cIds,
                                            ULONG cbStringMax,
                                            LONG iInitialSelection );

        Like WinInitComboBox, but loads the strings from a resource
        STRINGTABLE.  alId lists cIds string-table IDs; each string is
        loaded with WinLoadString using hmodRes (0 = current EXE) with
        a maximum length of cbStringMax bytes including the NUL.
        Returns 0 on success, 1 if memory could not be allocated.

32-bit port notes (relative to the 16-bit original)
----------------------------------------------------

    - halloc/hfree (16-bit huge-model allocators) replaced with
      malloc/free.
    - Parameter and result widths widened to the 32-bit PM ABI:
      WinLoadString returns LONG (was stored in a SHORT); combo control
      IDs are ULONG (WinSendDlgItemMsg takes ULONG idItem).
    - The window procedure msg parameter of the sample was declared
      ULONG, as required by the 32-bit PFNWP signature.
    - WinQuerySysValue results stored as LONG to avoid truncation on
      large displays.
    - EXPENTRY maps to _System in 32-bit os2.h; exported names are
      mixed case (WinInitComboBox, WinInitComboBoxFromRes).
    - Build system replaced with OpenWatcom wcc386 / wlink / wrc / wmake
      (see Makefile.wat).  lib\expm.lib is generated by
      "option implib=" as a side effect of the DLL link step.


Experimental changes from the 1990 original documented in this port
-------------------------------------------------------------------

    - Resource modules: hmodRes is documented as 0 = current module
      (WinLoadString semantics).
    - Empty/garbage strings: a string that fails to load is inserted as
      an empty item instead of copying an undefined buffer.


Building
--------

    compile_wat.cmd

Outputs: dll\expm.dll, lib\expm.lib, sample\combo\combosmp.exe.


Sample
------

sample\combo\combosmp.exe creates a standard window with two combo
boxes: the first is initialized from a resource STRINGTABLE
(WinInitComboBoxFromRes), the second from a hard-coded array
(WinInitComboBox).  It expects expm.dll to be on LIBPATH (or next to
the EXE).
